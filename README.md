# 💼 FinTech-ML-Portfolio

Exploratory modeling for financial assets using Prophet + Optuna. Modular notebooks, secure Git versioning via token, and compliant forecasting workflows.

Branch `preliminar` contains active development; `main` holds validated results.

A professional data science portfolio focused on predictive modeling, regulatory compliance, and asset-level forecasting in the financial sector.

## 🔍 Project Overview

This repository showcases exploratory modeling workflows applied to financial assets like **FUNO1** and **ADBE**, integrating time series forecasting techniques using **Prophet**, **Optuna**, and modular Python scripting.

It is designed to reflect the analytical rigor and compliance-conscious architecture expected in global financial institutions.

## 🧠 Core Components

- `1_notebooks/` — Jupyter notebooks for EDA, model prototyping, and pipeline documentation
- `2_scripts/` — Modular scripts for scalable model training, including `trainer.py`
- `.gitignore` — Configured to exclude compiled artifacts, model checkpoints, and local metadata
- `.env` (private, outside repo) — Personal Access Token for secure Git operations in Colab
